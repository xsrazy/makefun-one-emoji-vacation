One emoji for a dream vacation, entered for the make.fun bounty "One Emoji, One Dream Vacation". The emoji is **🍹** (tropical drink): one glance and the whole holiday arrives, the beach bar at golden hour, warm sand, the sun low over the sea, and the drink you only ever order when you are on vacation. It is the same dream as the island postcard, told from the chair on the sand rather than from a picture of the sand.

## Run it

```sh
python3 main.py
```

The program writes exactly one emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
